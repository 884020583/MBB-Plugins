# d100 检定规则基线（CoC 7e 习惯）

> 对应 issue #4。目标：把 d100 检定拆成可直接写进规格的条目，数值逐条给出处；官方免费材料没写死的，明确标为「设计取舍」。
>
> 来源分级：① Chaosium 官方 wiki（chaosium.com 站内规则页，下称「官网」）；② 官方免费 PDF（Quick-Start 规则、角色卡）；③ 授权/开源实现（Foundry CoC7、BCDice），仅用来验证官方文字的实现细节，不作为规则依据。

## 0. 结论速览

- 一次检定 = 1 个十位骰 + 1 个个位骰，读数 `十位×10 + 个位`，其中 `00 + 0 = 100`（官网 game-system）。
- 六档：大成功 `01` / 极难 `≤ 1/5` / 困难 `≤ 1/2` / 常规 `≤ 技能值` / 失败 `> 技能值` / 大失败 `96–100`（技能 < 50）或 `100`（技能 ≥ 50）。
- 奖励骰与惩罚骰各上限 2 颗，二者一比一抵消；对抗检定比成功等级，同级比技能值，技能同值再比骰面（低者胜）。
- 单次 SAN 损失 ≥ 5 → INT 检定 → 成功即临时性疯狂 1D10 小时，并掷 1D10 轮「疯狂发作」。
- 成长检定只在「本章成功用过」的技能上结算，且 `1D100 > 当前技能值` 才 `+1D10`。

## 1. 成功等级与阈值

| 等级 | 阈值（技能值 S） | 骰面条带 |
| --- | --- | --- |
| 大成功 Critical | 骰面为 01 | `1` |
| 极难 Extreme | `≤ ⌊S/5⌋` | `1 … ⌊S/5⌋` |
| 困难 Hard | `≤ ⌊S/2⌋` | `⌊S/5⌋+1 … ⌊S/2⌋` |
| 常规 Regular | `≤ S` | `⌊S/2⌋+1 … S` |
| 失败 Fail | `> S` 且未进大失败带 | `S+1 … 大失败下限-1` |
| 大失败 Fumble | `S < 50`：`96–100`；`S ≥ 50`：`100` | 见下 |

- 一律向下取整。官网「半分与五分」对照表即此口径（技能 45 → 困难 22、极难 9）。
- 大成功 `01` 同时高于极难，档位取最高；`01` 在任何难度要求下都算成功。
- 技能值 ≥ 100 时 `01–99` 必成功，但 `100` 仍是大失败（`00+0=100`），不存在「掷出 100 成功」；技能值 ≥ 50 时 `96–99` 不升级为大失败，技能 96–99 的角色掷出 96–99 仍是常规成功。
- 被要求困难/极难时，失败线不变，但「成功等级不足」按失败处理：骰面落在常规带而检定要求困难 → 该次检定失败。这条必须写进规格，否则「掷过就算过」。
- 大失败的判定基准默认取**原始技能值**；若按收窄后的有效阈值判定，则是实现取舍（见 §6）。

## 2. 奖励骰与惩罚骰

| 概念 | 机制 |
| --- | --- |
| 奖励骰 | 每颗多掷一个十位骰；与同一个个位组合，取结果**最小**者 |
| 惩罚骰 | 每颗多掷一个十位骰；取结果**最大**者 |
| 上限 | 各最多 2 颗（官网游戏机制；Quick-Start 在战斗机动处写明「最多两颗惩罚骰」） |
| 混合 | 奖励与惩罚一比一抵消，抵消后各自不超过 2 颗 |
| 用途 | 主要用在对抗检定与有利/不利环境；可替代升难度，也可叠加 |

实现算法（`00+0=100` 必须先归一化）：

```text
unit = 1..0 的个位骰
tens = 基础十位骰 + 奖励骰 - 惩罚骰 抵消后的十位骰集合
v(t) = (t == 0 && unit == 0) ? 100 : t*10 + unit
有惩罚骰 → 取 max(v)；有奖励骰 → 取 min(v)；都没有 → v(基础十位)
```

| 例子 | 十位集合 / 个位 | 候选值 | 结果 |
| --- | --- | --- | --- |
| 惩罚骰 1 | `{7, 3}` / 4 | 74、34 | 取 74 |
| 奖励骰 1 | `{0, 5}` / 0 | 100、50 | 取 50（下限被 100 拉高时仍取最小） |
| 惩罚骰 2 | `{9, 2, 6}` / 0 | 90、20、60 | 取 90 |

- 大成功仍只看最终选中的骰面是否 `01`；大失败仍按 §1 的技能值口径判定；奖惩骰须在掷前声明，掷后不可追加或撤销。

## 3. 对抗检定

| 情形 | 结果 |
| --- | --- |
| 成功等级不同 | 等级高者胜（大成功 > 极难 > 困难 > 常规 > 失败） |
| 等级相同 | 技能值高者胜 |
| 等级相同且技能值相同 | 双方再掷 1D100（或直接比本次骰面），**低者**胜 |
| 双方都失败 | 未产生结果：局面维持，Keeper 叙述僵持并决定是否重试（官方未规定，设计取舍） |
| 双方都大失败 | 双方各自承担最坏后果（官方未规定，设计取舍） |

- 对抗检定双方各掷一次，互不看对方结果调整难度；奖惩骰在掷前声明。
- 战斗特例（官网 combat）：闪避与攻击同级时**闪避方胜**；反击（fight back）需要成功等级**高于**攻击方才生效。规格里必须区分「闪避」与「反击」的平手处理。

## 4. SAN 损失

损失写成 `X/Y`：`X` = 检定成功时损失，`Y` = 检定失败时损失（官网 sanity）。

| 情形 | 损失 |
| --- | --- |
| SAN 检定成功（`≤` 当前 SAN） | 取 `X` |
| 检定失败（`>` 当前 SAN） | 取 `Y` |
| 检定大失败 | 取 `Y` 范围的最大值（实现参考 Foundry；官方未明说，设计取舍） |

| 边界 | 触发 | 结果 |
| --- | --- | --- |
| 单次损失 ≥ 5 | INT 检定 | 成功（`≤` INT）→ 理解真相，**临时性疯狂 1D10 小时**；失败（`>` INT）→ 本次不疯，之后可再次触发 |
| 临时性疯狂 | 持续 1D10 小时 | 掷 1D10 疯狂发作表，按轮演出：失忆 / 心身障碍 / 暴力 / 偏执 / 依托对象受威胁 / 昏厥 / 逃跑 / 歇斯底里 / 恐惧症（罚骰）/ 躁狂（罚骰） |
| 恢复 | 1D10 小时后 | 恢复清醒；新增的恐惧症、躁狂与背景改写**永久保留**；发作期间可被幻觉（delusion）影响，需再掷 SAN 做现实检验 |
| SAN = 0 | 立即 | 永久疯狂，角色退场 |
| 不定期疯狂 | 见 §6 | 长期状态，不靠 1D10 小时恢复 |

- 任何一次 SAN 损失（哪怕 1 点）都可让 Keeper 要求一次「不由自主的反应」，这是叙事权而非数值规则。

## 5. 技能成长

| 步骤 | 规则 |
| --- | --- |
| 标记 | 本章/本场内**成功**使用且有意义的技能打勾；失败不勾 |
| 结算 | 结算时对每个打勾技能掷 1D100 |
| 提升 | 掷骰 **严格大于**当前技能值 → `+1D10`；小于等于则不变 |
| 上限 | 官方免费材料未给硬上限；建议封顶 99（100 已视为自动成功，`00` 仍是大失败）——设计取舍 |
| 特殊 | 成长检定没有大成功/大失败，`01` 不特殊 |

- 注意方向：成长判定「失败」（掷高）才涨点，掷低不涨；不要实现成「掷低就涨」。

## 6. 来源冲突与设计取舍

| 争议点 | 官方文本 | 实现差异 | 本基线取值 |
| --- | --- | --- | --- |
| 大失败范围 | 角色卡速查写 `100/96+`，靠惯例理解 | Foundry `dice-pool.js`：`threshold < 50 ? 96 : 100`；BCDice：`difficulty < 50 ? 96 : 100` | 技能 < 50 → 96–100；技能 ≥ 50 → 100。角色卡写法有歧义，UI 需展开成中文 |
| 大失败是否随难度收窄 | 未明说 | Foundry 用收窄后的有效阈值（困难取 `⌊S/2⌋`） | v1 用原始技能值，留配置项 |
| 奖励/惩罚骰上限 | 官方游戏机制与 Keeper Rulebook 均为 2；Quick-Start 仅在机动处写明 | Foundry 常量 `maxDiceBonus = 2`、`maxDicePenalty = 2` | 2 颗 |
| SAN 大失败取最大值 | 免费材料未写 | Foundry 实现 | 采用，标为设计取舍 |
| 不定期疯狂触发 | 角色卡只给「起始 SAN 的 1/5」数值框；免费材料未写触发式 | Foundry 按「单日累计损失 ≥ 该值」触发 | v1 用「单日累计损失 ≥ 1/5 起始 SAN」，可配置 |
| 技能上限 | 未给 | —— | 99 |

## 7. v1 做 / 推迟

**v1 做：**

- 六档阈值表 + 向下取整 + `00+0=100`。
- 奖励/惩罚骰：各 ≤ 2、一比一抵消、取 min/max。
- 对抗检定：等级 → 技能值 → 骰面 三级平手；闪避与反击区分。
- SAN：`X/Y` 损失、单次 ≥ 5 触发 INT、临时性疯狂 1D10 小时、SAN=0 退场。
- 成长检定：只对打勾技能、严格大于才 `+1D10`、封顶 99。

**推迟（规格留钩子，v1 不实现）：**

- 幸运消耗改骰、推骰（push）与「推骰失败加重」。
- 疯狂发作 10 条全表：v1 只存表结构与 3 条示例文案。
- 恐惧症/躁狂的持久化与改名、心理治疗与 SAN 恢复、不定期疯狂完整规则。
- 技能 > 100 的例外规则、专精与技能分支。
